# Aegisy Client 2.5.2 for Windows

本版本修复 Windows 客户端对 npm 全局 CLI 的检测和安装，并包含 2.5.2 的界面与后台状态升级。

## 主要变化

- 修复已安装 Codex CLI 仍显示“未安装”的问题；Windows 会优先识别 npm 生成的 `codex.cmd`，不会误用同目录下的无扩展名 POSIX shim。
- 修复“桌面客户端与 Codex 能力”无法读取插件列表的问题；插件查询和安装现在可正确执行 npm 的 `codex.cmd` 入口。
- 更新或修复 Codex 前会检测 `codex.exe` 与 `codex-code-mode-host.exe`；仍在运行时明确提示关闭后重试，避免 npm 因 Windows 文件锁报 `EBUSY` 并连续失败。
- Codex 对应的 ChatGPT Windows 桌面客户端改为通过 Aegisy 美国节点代理下载，不再直接打开官方下载页面。
- 修复 Node.js 位于 `C:\Program Files\nodejs` 时，npm 安装命令因路径引号错误而无法启动的问题。
- CLI 更新完成后会对比 npm 包版本与当前实际命中的命令版本；存在多份安装且仍命中旧版本时不再误报“更新完成”。
- 扩展 Windows CLI 搜索目录，覆盖 npm 自定义 prefix、NVM、WinGet 和常见 Node.js 安装位置。
- Windows 发布包会执行 CLI 检测与批处理启动回归测试，并禁止覆盖已发布的相同版本号。
- 更新桌面界面和后台状态条，显示当前工具、模型、思考深度、上下文用量及账户余额。
- Codex 使用 Aegisy 自定义 Provider，启用 Web Search，并补齐第三方能力兼容请求头。

从早期 `2.5.1` 构建升级后，请重启 Aegisy Client；已经打开的终端仍需重启后才能读取新的认证环境。
