# Aegisy Client 2.5.2

本版本完成桌面界面、后台状态展示和 Codex 第三方 Provider 兼容能力升级。

## 主要变化

- 更新为更现代的科技感界面，重新整理顶部栏、侧边导航、配置档案和常用操作布局。
- 余额悬浮球升级为紧凑的后台状态条，显示当前工具、模型、思考深度、上下文用量与上限以及账户余额。
- 本地网关从真实请求和响应 usage 中读取 Token 用量；未观测到数据时明确显示未知，不生成虚假用量。
- 后台状态采集不记录提示词、响应正文或真实 API Key，仅保留运行状态与汇总用量。
- Claude、Codex、Gemini 和 OpenCode 支持精确档案激活、健康检查、托盘切换和配置备份回滚。
- Codex 激活改用 Aegisy 自定义 Provider，关闭 OpenAI 官方账号鉴权并写入第三方能力兼容请求头。
- Codex 显式启用实时 Web Search；`gpt-5.6-sol` 与 `gpt-5.6` 使用 372K 客户端上下文阈值和 high 思考深度。
- 配置体检会发现并修复缺失的 Codex 能力请求头、Web Search、鉴权和上下文字段，同时清理当前客户端不再支持的旧配置。
- PPT 生成和 Codex 插件操作移出主界面线程，长时间任务期间窗口保持可响应。

macOS 发布包为 Apple Silicon 版本。当前构建使用 ad-hoc 代码签名和 Sparkle Ed25519 更新签名，未进行 Apple 公证。
