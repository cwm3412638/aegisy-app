# Aegisy Client 2.5.0

本版本新增本地网关、用量中心、连接测试、CLI 在线版本检测、激活前配置预览、系统原生终端启动和桌面增强中心。

## 主要变化

- 本地网关默认关闭，仅监听 `127.0.0.1:43112`。
- Claude、Codex、Gemini 分别使用独立本地路由，切换档案时无需向终端暴露真实 Aegisy Key。
- 请求监控只记录元数据，不保存提示词、回复和工具参数。
- 右上角余额入口升级为用量中心，展示服务端真实用量与 Key 消费。
- 新建档案可在保存前验证 Key、模型和网络延迟。
- 激活档案前展示配置文件和字段变更，并继续使用自动备份与失败回滚。
- “启动”使用系统原生终端，并自动清除会覆盖当前档案的旧 Provider 环境变量。
- 系统体检只在本地 CLI 版本落后时显示更新按钮，最新版显示“已是最新”。
- “桌面增强”展示 Codex 官方市场的完整插件列表，并可安装所选插件和 Computer Use。
- Codex 历史会话可以同步到当前 Provider；JSONL 和 SQLite 写入前均会备份。
- Claude Desktop 支持 Windows、macOS 运行时中文注入，不修改官方安装文件。
- 模型列表直接使用 Aegisy API Key 返回的全部结果，不使用客户端内置白名单过滤。
- 点击头像可修改登录密码或使用密卡兑换，兑换成功后余额自动刷新。
- API Keys 支持创建、编辑、切换分组、启用、禁用和删除。
- Codex 插件列表提供中文用途说明，并支持多选批量安装和安装结果汇总。
- 新增 AI 对话工作区，可切换账号 API Key 和该 Key 可用模型，支持多会话、Markdown、流式回复与停止生成。
- 支持复制消息与完整对话、编辑后重发、直接重发、重新生成，以及实际/估算上下文 Token 展示。
- 对话历史保存在当前用户的本机应用数据目录，重启后可恢复；历史文件不包含 API Key。
- 用户消息和助手回复增加独立头像，长对话中更容易识别发言角色。
- 修复批量选择大量插件时安装确认弹窗被内容撑高、底部按钮超出屏幕的问题。
- 新增 Skills 管理、HTTPS/本地完整技能包安装、启用禁用、权限状态和第三方脚本隔离策略。
- 对话支持自动或通过 `/image`、`/ppt` 调用 GPT Image 和 PPT 制作 Skill，并在消息中展示生成产物。
- 修复 macOS 开发构建复用旧打包 Bundle 时可能出现的 Qt Cocoa 插件冲突。

本地网关依赖 Node.js；缺少时可通过“系统体检”安装运行环境。
