# Remotion 视频制作

先定义 Composition 的宽高、帧率、时长和输入数据结构，再拆分为可复用场景组件。动画必须由帧号驱动，避免依赖真实时间、随机状态或网络时序。

为文字、图片、音频和视频建立稳定尺寸，预加载媒体并处理加载失败。批量任务把文案、颜色、素材和时长放在输入数据中，不复制整套组件。

渲染前在多个关键帧预览，检查文字溢出、转场边界和音频波形。最终导出后验证编码、时长和画面完整性。
