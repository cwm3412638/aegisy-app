# Manim 动画制作

先把主题拆成短镜头，明确每个镜头要解释的概念、画面对象、动画顺序和旁白。复杂公式分步出现，变量颜色保持一致，坐标轴、标签和图例必须可读。

按场景编写 Manim 代码，优先使用可复用函数和参数。先低质量快速渲染关键镜头，确认构图与节奏后再高质量导出。使用 LaTeX 前检查本机环境，并为缺失字体或公式工具提供降级方案。

交付前检查对象遮挡、公式错误、镜头停留时间、首尾空帧和视频编码。
