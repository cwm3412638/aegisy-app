# FFmpeg 视频处理

先用 `ffprobe` 检查容器、编码、时长、帧率、分辨率、色彩空间和音轨，再选择命令。能无损截取或封装时优先流复制；需要滤镜、缩放、变速或字幕时再重新编码。

输出到新文件，不覆盖源文件。明确目标平台后设置画幅、码率、像素格式和音频编码。字幕烧录前检查字体可用性、换行、安全边距和时间轴。

处理完成后再次用 `ffprobe` 验证，并抽查开头、中间、结尾画面以及音画同步。
