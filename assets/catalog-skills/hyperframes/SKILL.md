# HyperFrames 视频制作

先确认画幅、时长、受众、品牌风格和交付格式。读取素材后生成按秒标注的分镜，明确每个镜头的文案、视觉层级、动效、转场和配音。

优先使用 HTML/CSS/JavaScript 构建可复用场景，保持字体、颜色和安全边距一致。渲染前检查长文本溢出、移动端画幅和素材清晰度。使用本机浏览器渲染画面，并通过 FFmpeg 合成、配音和导出。

不要覆盖原始素材。交付前检查首尾帧、字幕时序、音量峰值、黑帧和目标分辨率。
