# OpenMontage 工作流

把任务拆成脚本、镜头表、素材清单、配音、字幕、时间线、渲染和质检八个阶段。每个阶段都输出可检查的中间文件，并记录输入、输出和失败原因。

先锁定画幅、时长、语言、旁白风格和素材授权，再生成镜头表。素材缺失时明确标记占位，不用无关素材填充。字幕以配音时间轴为准，剪辑节奏以句子和镜头语义为边界。

渲染前校验全部文件路径和时长，渲染后检查黑帧、静音、重复镜头、字幕越界和音量一致性。
