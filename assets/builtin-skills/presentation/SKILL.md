# PPT 制作

先明确主题、受众、场景、页数和视觉风格。使用钩子、背景、主体、转折和结论组织叙事，避免把文档段落直接搬到幻灯片。

优先在 `editorial` 杂志风与 `swiss` 瑞士网格中选择一套。根据内容使用封面、章节、观点、要点、对比、流程、指标和收尾布局；每页只表达一个主要观点，正文不超过 5 条。

由当前会话模型生成结构化计划，再使用隔离的 `python-pptx` 运行环境生成可编辑 PPTX。首次使用需要在 Skills 管理中安装 PPT 运行环境。生成后检查标题换行、正文溢出、字体替换、页码、对齐和投屏可读性。
